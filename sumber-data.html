REFERENCE DESK / SUMBER & METODOLOGI

Informasi yang baik
dimulai dari sumbernya.

Atlas Bumi adalah proyek edukasi. Halaman ini menjelaskan mana konten referensi, mana alat eksternal, dan bagaimana angka perlu ditafsirkan.

i
Transparansi data

Versi ini sengaja tidak menampilkan angka cuaca atau gempa yang berpura-pura real-time. Konten utama merupakan materi pengantar. Jam dan timer dihitung lokal oleh browser. Untuk kondisi terkini, buka sumber resmi atau visualisasi eksternal yang tercantum.

01 / DATA

Tidak mengarang angka langsung.

Jika API tidak diintegrasikan atau gagal diakses, halaman tidak akan mengganti data dengan angka palsu.

02 / JAM

Zona waktu dari browser.

Jam dunia menggunakan JavaScript Intl dan zona waktu IANA. Tidak memerlukan permintaan jaringan.

03 / PRIVASI

Timer berjalan lokal.

Penghitung sesi memakai penyimpanan sesi browser. Tidak ada pengiriman durasi ke server atau analitik pada project ini.
